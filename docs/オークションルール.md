## 1. 役割

| 役割 | 別名 | 説明 |
| --- | --- | --- |
| 入札者 | 秘密の買い手 | ポイントで入札し、落札すれば秘密を閲覧できる |
| 出品者 | 秘密の売り手 | 秘密を登録・出品し、出品・落札に応じてポイントを得る |
| 主催者 | オークションディーラー | 競りごとにランダム選抜。進行役。自身は入札不可 |

1 つの競りにおいて、同一ユーザーが複数役割を兼ねることはない（出品者 ≠ ディーラー、ディーラーは入札不可）。

## 2. 秘密の出品フロー

### 2.1 競り前

1. **登録**  
   出品者は任意の秘密を登録できる。
2. **価格の自己設定と妥当性チェック**  
   新規登録時、出品者が決めた額で秘密を登録する。  
   額と内容が見合っているかは、AI 等による validation を想定する。
3. **登録 ≠ 出品**  
   登録した段階ではまだオークションには出ない（在庫・下書き扱い）。
4. **出品の実施**  
   出品を実施すると、出品者以外のグループメンバーから**ディーラーがランダムに割り当てられ**、出品確定時点で**出品価格と同額（100%）**のポイントが出品者に振り込まれる（P4）。  
   オークション自体は**まだ開始しない**（開催待ち。§3.1 参照）。

### 2.2 競り後

5. **落札時の追加報酬**  
   落札価格の**追加振込はない**（P5）。落札価格は §3.4 の按分比でそのまま出品者・ディーラーに分配される。
6. **不落札時の返却**  
   落札されなかった場合、「価値のない秘密」とみなし、本来価格より**20% 目減りした秘密**（次回出品時の価格に反映）が、出品前ステータスで返却される（P6）。
7. **不落札時のポイント没収**  
   6 の場合、4 で一度振り込まれたポイントは**全額没収**される（目減り率とは別の扱い）。  
   残高が足りない場合は**借金（マイナス残高）**になり得る（上限・自動返済なし。P11）。

### 2.3 秘密ステータス（案）

```text
registered（登録済み・未出品）
  → listed / pending_dealer_approval（出品実施・ディーラー承認待ち）
  → on_auction（競り中。ディーラー承認後、開放時間が経過するまで）
  → sold（落札）
  → returned（不落札・目減りして登録済みへ戻る）
```

## 3. オークション（テーブル）ルール

### 3.1 開催単位

- オークションテーブル（競りの場）は**グループ単位**と一致する。
- 出品が確定すると、出品者以外のグループメンバーから**ディーラーがランダムに割り当てられる**（3.1.1 参照）。
- 開始価格は**出品価格と同額**（加算・倍率なし。P3）。
- 開催後は、**幹事がグループ単位で設定した時間**オープン（入札可能）な状態になる（既定 24 時間。P2）。
- 1 グループで**同時に複数の競り**を開催できる。

#### 3.1.1 ディーラー承認とオークション開始（P1・確定）

- 出品確定 → ランダム選抜されたディーラーに割り当て通知 → **ディーラーが承認した時点でオークションが開始**する（固定の待機時間はない）。
- 承認には**タイムアウトを設けない**。ディーラーが承認するまで無期限に「ディーラー承認待ち」の状態が続く（運用上のリスクとして `PRD.md` §9 に記載）。
- ディーラーは、承認する前であれば**辞退**できる（§4.4）。オークション開始（承認）後の辞退は不可。

### 3.2 参加資格

| 対象 | 入札 | 備考 |
| --- | --- | --- |
| グループメンバー（出品者含む） | 可 | 出品者は**自出品への入札不可**（P8・確定） |
| ディーラー（当該競り） | 不可 | 進行役のため入札できない |

### 3.3 入札の可視性（情報非対称）

- **出品者**は、誰が入札したか分かる。
- **ディーラー**も、誰が入札したか分かる（P9・確定。進行を盛り上げるための開示）。
- **出品者・ディーラー以外**（他の参加者・傍観者）は、誰が入札したか分からない。

### 3.4 入札価格の分配

- 入札（落札）で動いたポイントは、**出品者 70% : ディーラー 30%** で按分する（P7・確定）。追加振込（P5）はない。

## 4. ディーラー

### 4.1 選抜

- 出品者**以外**のグループメンバーから、ランダムにディーラーを選抜する。
- 競りごとに独立して割り当てる（同時開催時は競りごとに別ディーラーになり得る）。

### 4.2 権限・見える情報

- ディーラーは、**出品者**と**売りに出された秘密の概要**を把握できる。
- **本文（中身）は見られない**。

### 4.3 役割

- 秘密の概要から、「誰の・何に関する秘密か」を参加者に説明し、競りを盛り上げ・加速させる。
- 自身は当該競りに入札できない。

### 4.4 辞退（確定・P12）

- 割り当てられたディーラーは、**出品価格の 5%** を支払うことで辞退できる。辞退料は**完全没収**（グループへの還元・プールなし。システム消滅）。
- 辞退料の目的は、進行役の負担を軽減しつつ、安易な辞退を抑えること。
- 辞退後は、残りのグループメンバーから**別のディーラーを再割当**する。**再割当の回数上限はなし**（辞退のたびに 5% ずつ没収されるため、実質的な歯止めになる想定）。
- 辞退が可能なのは**オークション開始（ディーラー承認）前のみ**。開始後の辞退は不可。

## 5. パラメータ一覧（P1–P12・2026-08-17 全確定）

詳細値は `PRD.md` §6 を正とする。本節は要点のみ。

| ID | 項目 | 確定値 |
| --- | --- | --- |
| P1 | 出品実施〜開催までの待機時間 | 固定時間なし。ディーラー承認で開始（タイムアウトなし） |

| P7 | 入札額のディーラー / 出品者按分比 | 出品者 70% : ディーラー 30% |
| P8 | 出品者の自出品への入札可否 | 不可 |
| P9 | ディーラーへの入札者開示 | 開示する |
| P10 | 額と内容の AI validation 基準 | MVP では実施しない |
| P11 | マイナス残高の上限・返済ルール | 上限なし・自動返済なし |
| P12 | ディーラー辞退料 | 出品価格の 5%・完全没収・開始前のみ・再割当上限なし |

## 6. プロダクト方針メモ

### 6.1 ショップ機能は廃止

- **ショップ（固定価格での即時購入）は設けない。**
- 秘密の獲得手段はオークション（本ルール）に一本化する。
- 既存の `docs/機能要件.md` §6・画面のショップ記載は旧案として残すが、実装対象外。

## 8. 不変条件（既存方針との接続）

- ポイント・秘密・オークションは**グループ完全分離**（他グループへ漏れない）。
- 扱う秘密は**本人が公開してよい内容のみ**。
- 入札・ウォレット増減・按分は、レースや二重払いを防ぐため PostgreSQL Function 等での整合を前提とする（`docs/技術選定.md`）。
