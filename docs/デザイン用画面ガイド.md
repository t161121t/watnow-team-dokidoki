## 0. このプロダクトは何か

仲のいい友達グループで、**本人が公開してよい「秘密」** をオークション形式でやり取りするコミュニケーションゲーム。

```text
グループに入る
  → 秘密を登録する（まだ出品ではない）
  → チャレンジでポイントを稼ぐ（そのグループの財布だけ）
  → 秘密リストから出品する
  → ディーラーが承認すると競りが始まる
  → 入札して落札した人だけ本文を読める
```

固定価格のショップはない。秘密の獲得はオークションのみ。

## 1. デザインの前提

### 1.1 デバイス・媒体

| 項目 | 前提 |
| --- | --- |
| 形態 | **PWA 一本**（ネイティブアプリは作らない） |
| 優先 | **スマートフォン縦向きを第一**。狭い幅でも 5 タブが成立すること |
| インストール | 初回周辺で「ホーム画面に追加」案内が必要（iOS は追加しないと通知が使えない） |
| リアルタイム | 入札・現在価格・残り時間は待たずに更新される想定 |

PC 用の別レイアウトは必須ではない。モバイルの情報設計がそのまま広がる形でよい。

### 1.2 常設ナビ（グループ選択後）

下タブ **5 つ**。表示名は確定。

| タブ | 行き先 | このタブの仕事 |
| --- | --- | --- |
| ホーム | ⑥ | いまのグループの状況を一目で把握する |
| 秘密リスト | ⑬ | 自分の秘密の管理・出品・ディーラー担当 |
| チャレンジ | ⑧ | ポイントを稼ぐ |
| オークション | ⑨ | グループ内の競りを見て会場へ入る |
| マイページ | ⑭ | 自分のポイント・コレクション・設定 |

ショップタブは無い。

### 1.3 デザインで守るルール

| ルール | 画面への効き方 |
| --- | --- |
| **グループ完全分離** | ポイント・秘密・オークションは選択中グループのみ。合算・送金の UI を作らない |
| **本文は落札まで秘匿** | 一覧・会場・ディーラー画面に本文を出さない。出すのは登録者本人と落札後の⑫だけ |
| **情報の非対称** | 同じオークションでも、入札者 / 出品者 / ディーラーで見えるものが違う（§2） |
| **本人が公開してよい秘密だけ** | センシティブ誘導・煽りコピーは避ける。登録時に注意文を置く |
| **マイナス残高はあり得る** | ポイント表示は 0 以下も想定する。入札ボタンは残高不足なら押せない |

`画面.md` の黄・緑・青は遷移図の層分け用で、**ブランドカラー指定ではない**。

### 1.4 MVP に入れないもの（画面に出さない）

| やらない | メモ |
| --- | --- |
| ⑪ ショップ | 固定価格の即時購入は廃止 |
| 招待コード / QR / 参加リンク | 幹事がニックネーム検索して直接招待 |
| コメント / リアクション | ⑫ にも付けない |
| 他メンバーの残高ランキング | 自分の残高だけ見せる |
| 通知設定 | アカウント設定から外す（Phase 2） |
| 公開先グループの複数選択 | 登録は選択中グループ前提 |
| 称号・実績・ウォッチリスト | 後回し可 |
| 秘密の AI 審査 | 登録時の「内容チェック中」UI は不要 |

チャレンジの中身（何のゲームか）は未定。⑧は **枠だけ** デザインする。

## 2. 3 つの役割と「見える情報」（最重要）

1 つの競りで、同じ人が複数役割を兼ねない。

| 役割 | 別名 | 何をする人か |
| --- | --- | --- |
| 入札者 | 買い手 | ポイントで入札する。落札したら本文を読める |
| 出品者 | 売り手 | 秘密を登録・出品する。自出品には入札できない |
| 主催者（ディーラー） | 進行役 | 競りごとにランダム選抜。盛り上げる。当該競りには入札できない |

### 2.1 同じオークションで誰に何を見せるか

| 情報 | 入札者（会場 ⑩） | 出品者（詳細 ⑯） | ディーラー（詳細 ⑯） |
| --- | --- | --- | --- |
| 出品者の名前 | 見せてよい（公開情報） | 自分 | 見せる |
| 秘密のタイトル（title） | 見せる | 見せる | 見せる |
| 秘密の概要（summary） | **見せない**（ディーラー限定） | 見せる（自分が書いた） | **見せる（進行の材料）** |
| 秘密の本文 | **落札するまで見えない** | 自分の秘密なので見える（⑯では必須ではない） | **絶対に見せない** |
| カテゴリ / レア度 | 見せる | 見せる | 見せる |
| 現在価格 / 残り時間 | 見せる | 見せる | 見せる |
| 入札した人の名前 | **見せない** | **見せる** | **見せる** |
| 入札額の履歴 | 額と時刻のみ（匿名） | 誰がいくら、が分かる | 誰がいくら、が分かる |
| 入札ボタン | ある（条件付き） | **ない** | **ない** |
| ディーラー承認 / 辞退 | ない | ない | 開始前だけある |

⑩ と ⑯ と ⑫ は見た目を寄せすぎないこと。役割が違う画面。

```text
入札したい人   ⑨ 一覧 → ⑩ 会場 →（落札後）⑫ 本文
出品した人     ⑬ リスト → ⑯ 関連詳細（入札者の顔が見える）
ディーラー     ⑬ リスト → ⑯ 関連詳細（概要だけで進行、本文なし）
```

## 3. 画面マップ

```text
① ログイン・オンボーディング
    ├── グループ未所属 → ③ 招待の確認 / ④ グループ作成 → ⑥ ホーム
    └── 所属あり → ⑥ ホーム
            ├── ② グループ切替 → ③ / ④
            ├── ⑤ グループ管理（幹事のみ）
            ├── ⑬ 秘密リスト（タブ）
            │       ├── ⑦ 秘密を追加
            │       └── ⑯ 関連秘密詳細（出品者 / ディーラー）
            ├── ⑧ チャレンジ（タブ）
            ├── ⑨ オークション一覧（タブ）
            │       └── ⑩ オークション会場
            │               └── ⑫ 秘密ビューワー（落札後）
            └── ⑭ マイページ（タブ）
                    ├── ⑮ アカウント設定
                    └── ⑫ 秘密ビューワー（コレクション）
```

番号は社内の画面 ID。⑪は欠番（ショップ廃止）。

## 4. 共通パーツ（先に決めると楽）

画面をバラす前に、使い回す塊を決めておく。

### 4.1 ポイント残高

- 常に **選択中グループの財布** だけを出す
- グループ切替と同時に数字が変わる
- **マイナス**（例: −120 pt）をエラーに見せすぎない。入札不可の理由表示とは分ける
- 単位表記（pt / ポイント）は統一する

入札ボタン横やヘッダーに残高を置く画面: ⑥ ホーム、⑨ 一覧、⑩ 会場、⑬ 秘密リスト。

### 4.2 秘密カード（本文なし）

一覧・ハイライト用。本文は入れない。

| 出す | 出さない |
| --- | --- |
| 出品者のニックネーム / アイコン | 本文 |
| カテゴリ（恋愛 / 黒歴史 / 趣味 / 特技 など） | 入札者の名前（一覧では出さない） |
| レア度（自己申告 1〜5） | 他グループの情報 |
| タイトル（短い title） | 概要（summary。ディーラー限定） |
| 現在価格・残り時間（競り中） | |
| 状態ラベル（開催待ち / 競り中 など） | |

### 4.3 状態ラベル（秘密）

ユーザー向けの言葉はデザインで整えてよい。意味は変えない。

| 内部状態 | ユーザーに伝えたいこと |
| --- | --- |
| `registered` | 登録済み。まだ出品していない |
| `listed` / ディーラー承認待ち | 出品した。ディーラーの承認待ち。競りはまだ始まっていない |
| `on_auction` | いま競り中 |
| `sold` | 落札された。本文は落札者だけが⑫で読む |
| `returned` | 売れ残った。価値が 20% 目減りして戻ってきた。再出品できる |

### 4.4 オークション状態

| 状態 | ユーザーに伝えたいこと |
| --- | --- |
| ディーラー承認待ち | まだ入札できない |
| オープン（競り中） | 入札できる。カウントダウンあり |
| 終了処理中 | しばらく待つ（確定中） |
| 落札 | 勝者が決まった |
| 不落札 | 入札がなかった / 成立しなかった |

### 4.5 確認が必要な操作

誤操作がお金（ポイント）と秘密の公開に直結する。次は必ず確認ダイアログかそれに準ずるステップを置く。

- 出品する（直後に出品価格と同額が振り込まれる。不落札なら全額没収され、残高がマイナスになり得る）
- 入札する
- ディーラー承認（承認した瞬間にオークション開始）
- ディーラー辞退（出品価格の 5% を払う。戻ってこない）
- 秘密の削除
- グループ脱退（そのグループのポイントは消える）
- メンバーのキック

### 4.6 空・不可・不足

どの主要一覧にも空状態を用意する（秘密ゼロ、競りゼロ、招待ゼロ、コレクションゼロ）。

入札できないときは、押せないだけでなく理由を出す。

- 残高が足りない
- 自分の出品である
- 自分はこの競りのディーラーである
- まだディーラー承認前である
- オークションが終了している

## 5. 画面ごとの役割と必要な機能

凡例:

- **役割**: この画面の仕事
- **置くもの**: デザインに必要な情報
- **操作**: ユーザーができること
- **状態**: 用意するバリエーション
- **注意**: デザイン判断で特に効く制約
- **未確定**: 仕様が空いているので提案してよい / 確認が要る

---

### ① オンボーディング・ログイン

**役割**: アカウントを作り、アプリに入れる。グループ未所属なら③④へ、所属ありなら⑥へ。

**置くもの**

- アプリの一文（友達の秘密をオークションで知る、程度）
- ログイン / アカウント作成
- ニックネーム
- アイコン（未設定でも進める想定。空アイコンのデフォルトが必要）
- PWA「ホーム画面に追加」案内

**操作**

- ログイン / 新規登録
- ニックネーム・アイコン設定
- ホーム画面追加の手順提示（特に iOS）

**状態**

- 未ログイン
- ログイン済みだがプロフィール未設定
- グループ未所属 / 所属あり
- インストール案内の表示 / スキップ後

**注意**

- 認証方式（メール、Magic Link、Google 等）は本番で変わる。特定プロバイダにロックしたビジュアルにしない
- 秘密そのものはこの画面に出さない

**未確定**: オンボーディングを何枚のストーリーにするか、追加案内をモーダルにするか。デザイン提案可

---

### ② グループ切り替え

**役割**: 所属グループを選び直す。ポイント表示もここで切り替わる。

**置くもの**

- 各グループのアイコン・名前
- **そのグループのポイント**（グループごとに別の数字）
- いま選択中である印
- 「未読」があればバッジ（定義は未確定。招待・お知らせ想定）

**操作**

- グループをタップして切替 → ⑥へ
- 招待の確認（③）へ
- グループ作成（④）へ

**状態**

- 1 グループのみ
- 複数グループ
- 招待が届いている
- ポイントがマイナスのグループが混ざっている

**注意**

- 全グループ合計ポイントは出さない
- 切替直後、ヘッダーの残高・オークション・秘密リストは全部そのグループのものに見えること

**未確定**: 「未読」の対象。数字の定義が決まるまで、バッジの見た目だけ用意しておいてよい

---

### ③ 招待の確認

**役割**: 自分宛の招待を承諾または辞退する。招待コード入力画面ではない。

**置くもの**

- 招待一覧（`invited` のものだけ）
- グループ名 / アイコン
- 招待した人のニックネーム
- 承諾 / 辞退

**操作**

- 承諾 → そのグループの⑥へ（ポイント財布が作られる）
- 辞退 → 一覧から消える
- 招待ゼロなら空状態＋「グループを作る」導線

**状態**

- 招待 0 件 / 複数件
- 承諾処理中

**注意**

- QR・コード・リンク貼り付け欄は置かない
- 見知らぬ人向けの「グループを探す」は作らない

---

### ④ グループ作成

**役割**: 新しい友達グループを作る。作った人が最初の幹事。

**置くもの**

- グループ名
- グループアイコン
- 作成後にどう招待するかの短い説明（幹事がニックネーム検索して招待する）

**操作**

- 作成 → ⑥へ
- キャンセル

**注意**

- 招待コード発行・リンクコピーはこの画面に置かない
- 作成時点ではメンバーは自分だけ

---

### ⑤ グループ管理（幹事のみ）

**役割**: メンバーと、オークションの開放時間を管理する。一般メンバーは入れない（または閲覧のみ。編集は幹事）。

**置くもの**

- メンバー一覧（アイコン・ニックネーム・役割：幹事 / メンバー）
- ニックネーム検索（2 文字以上。候補は最大 20。すでにメンバーは出ない）
- オークション開催時間（既定 24 時間。この値だけグループごとに変えられる）
- 招待中（まだ承諾していない人）が分かると親切

**操作**

- ユーザーを検索して招待
- キック
- 幹事権限の付与
- 開催時間の変更
- （任意）招待の取り消しは仕様にないので、未記載なら置かない

**状態**

- メンバーが少ない
- 招待済み未承諾がいる
- 自分以外に幹事がいない（自分は脱退できない、という制約の説明が要る場面）

**注意**

- ショップ価格設定は廃止。置かない
- 開催時間以外のオークション数値（按分 70:30、辞退料 5% 等）は全グループ共通。ここでは触らせない
- 他メンバーのポイント残高は公開しない

**未確定**: 開催時間の入力 UI（プリセット「12時間 / 24時間 / 48時間」か自由入力か）。デザイン提案可

---

### ⑥ ホーム

**役割**: 選択中グループの「いま」を見せ、タブや管理へつなぐハブ。

**置くもの**

- グループ名 + 切替導線（②へ）
- 自分の保有ポイント（このグループ）
- 開催中オークションのハイライト（カード数枚。⑨と同じ情報密度でよい）
- お知らせ（ディーラー指名、招待、競りの開始・終了、チャレンジ承認待ちなど）
- 幹事ならグループ管理（⑤）への入口

**操作**

- グループ切替
- ハイライトから⑩へ
- お知らせの該当画面へ
- タブで⑬⑧⑨⑭へ

**状態**

- 競りが 0 件
- 競りが複数同時開催
- 自分がディーラー承認待ち
- ポイントマイナス
- グループ未参加は原則来ない（①③④側）

**注意**

- 他グループのポイントや秘密を混ぜない
- 本文をホームに出さない

**未確定**

- お知らせの種類と既読管理
- ハイライトの並び（残り時間が短い順、など）
- ディーラー承認待ちをホームに出すか（一覧⑨にも関わる。U2）

---

### ⑦ 秘密を追加する

**役割**: 公開してよい秘密を **登録** する。ここではまだオークションに出さない。

**置くもの（入力）**

| 項目 | 内容 |
| --- | --- |
| 本文 | 落札されるまで本人以外は見られない本文 |
| 概要 | 一覧・ディーラー進行用の短い説明。本文のネタバレしすぎない |
| カテゴリ | 恋愛 / 黒歴史 / 趣味 / 特技 など（初期はこの程度） |
| レア度 | 自己申告 1〜5 |
| 出品価格 | 自分で決める整数。開始価格はこの額と同じ |

登録時の注意文: 本人が話してよい内容だけ。落札後は取り下げられない。

**操作**

- 登録（確認ダイアログ推奨）→ ⑬に載る（状態: 登録済み）
- キャンセル

**置かない**

- 公開先グループの複数チェック（MVP 外。選択中グループに入る）
- AI 審査の待ち画面
- 「すぐに出品する」を必須にしない。出品確定は⑬

**旧ドキュメント注意**: `機能要件.md` の「公開タイミング（即時 / 次回まで非公開）」は現行 PRD / DB に無い。**登録＝在庫、出品は別操作** でデザインする。

**注意**

- 本文エリアは十分な高さ。概要は短く（プレースホルダで「進行役が読み上げる用」と示すと役割が伝わる）
- レア度はゲーム的に見せてよいが、公式な希少性ではない（自己申告）

---

### ⑧ チャレンジ

**役割**: 選択中グループのポイントを稼ぐ場所。

**置くもの（枠）**

- チャレンジ一覧（タイトル、説明、報酬ポイント、写真提出の要否、クールダウン）
- 提出 / 挑戦
- 承認待ち（他メンバーの提出を承認 / 却下。自己承認は不可。MVP は **1 人の承認で付与**）
- 自分の履歴
- クールダウン中なら再開までの表示

**操作**

- 挑戦する
- 証拠写真を出す場合がある（中身未定なので、写真あり/なし両方のカードを用意）
- 他人の提出を承認 / 却下
- 履歴を見る

**状態**

- 挑戦可能
- クールダウン中
- 承認待ち（自分 / 他人）
- 承認されてポイント加算
- 却下

**注意**

- ポイントは **いま選択中のグループにだけ** 入る。全グループ一斉加算の表現は禁止
- **提供コンテンツは未定**。具体的なゲーム名やミッション文は仮でよく、「枠のデザイン」が成果物
- 旧要件の「複数人承認」は撤回。承認者は 1 人で足りる UI

**未確定**: システムが用意するゲーム内容、報酬額、クールダウン時間、幹事が独自チャレンジを作る UI を MVP に入れるか

---

### ⑨ オークション一覧

**役割**: グループ内の競りを眺めて、入札しに⑩へ入る。出品・ディーラー作業の主戦場ではない（それは⑬）。

**置くもの**

- カード: 出品者、カテゴリ、レア度、概要、現在価格、残り時間、状態
- 同時に複数枚並ぶ
- ソート / フィルター（価格、残り時間、カテゴリ、レア度など）

**操作**

- カードタップ → ⑩（競り中・入札できるもの）
- 自分の出品やディーラー担当は⑬寄りだが、一覧から⑯へ飛ばすかはデザイン判断可（役割が混ざるので、基本は⑩＝入札用と割り切ってよい）

**状態**

- 0 件
- 開催待ちだけある
- 競り中だけある
- 混在
- 自分が入札できないカード（自出品 / ディーラー担当）が混ざる

**注意**

- 入札者名は出さない
- 本文は出さない
- 残高不足でもカードは出す。入れなくするのは⑩側

**未確定（U2）**: ディーラー承認待ちのカードを⑨に出すか、⑬とホームだけにするか。**一覧が入札会場の入口なら、承認待ちは出さない / 出しても「まだ入札できない」と明示する** のが分かりやすい

---

### ⑩ オークション会場（入札用）

**役割**: **入札する人のための競りの場。** ⑨から来る。

**置くもの**

- 出品者（名前・アイコン）
- カテゴリ / レア度 / 概要
- 現在価格（リアルタイム）
- 残り時間（カウントダウン。終了時刻はディーラー承認時に確定）
- 自分のこのグループの残高
- 入札履歴: **金額と時刻（と順位）だけ。名前は出さない**
- 入札入力（現在価格より上）
- 入札ボタン

**操作**

- 入札する（確認あり）
- 終了後、自分が落札していれば⑫へ

**入札ボタンを無効にする条件**

- 残高 < 入札額
- 自分の出品である
- 自分はこの競りのディーラーである
- 承認前 / 終了済み

**置かない**

- 他の入札者の名前
- 本文
- 出品者向けの「誰が入札したか」リスト（それは⑯）
- ウォッチリスト（Phase 2）

**状態**

- 競り中（通常）
- 自分が最高額
- 追い抜かれた
- 終了直後（確定中）
- 落札（自分 / 他人）
- 不落札
- 自分は見て入札できない立場（自出品・ディーラー）※ここに来てしまった場合の説明

**注意**

- 負けた入札のポイントは消費されない（拘束しない）。「今の最高額を出しても、負けたら戻る」ではなく **最初から引かれない**。コピーで「仮押さえ」と書かない
- 現在価格と履歴はリアルタイム。スケルトンや遅延より、数字が動く感じが体験の中心
- ディーラー承認前は本来ここではなく⑬⑯。誤って来たら開催前と出す

---

### ⑫ 秘密ビューワー

**役割**: 落札した秘密の **本文を読む**。出品者・ディーラーの管理画面ではない。

**入口**

- ⑩で自分が落札したあと
- ⑭のコレクションから

**置くもの**

- 本文
- 概要 / カテゴリ / レア度
- 出品者
- どのグループで落札したか（タグ）
- 落札日・落札額（あるとコレクションとして成立しやすい）

**置かない**

- コメント
- リアクション
- 非公開に戻すボタン（落札後は取り下げ不可）

**操作**

- 読む
- コレクション一覧へ戻る

**状態**

- 通常の閲覧
- 本文が長い
- 自分がオーナーで未公開の秘密を誤って⑫で開こうとする、は主経路ではない（編集は⑬⑦側）

**注意**

- 本文が主役。オークションの装飾を残しすぎない
- スクリーンショット対策までは仕様にない。過度な隠しは必須ではないが、センシティブであることはトーンで示す

---

### ⑬ 自分の秘密リスト（タブ「秘密リスト」）

**役割**: 自分に関係する秘密のハブ。**ステータス管理・出品確定・ディーラー UI をここに集約する。** 新しい中核画面。

大きく 2 ブロックあると分かりやすい。

#### A. 自分の秘密

**置くもの**

- 状態ラベル（§4.3）
- 概要・カテゴリ・レア度・いまの価値（価格）
- 不落札戻りなら「20% 目減りした」ことが分かること

**操作**

| 状態 | できること |
| --- | --- |
| 登録済み | 編集・削除、**出品する** |
| 承認待ち | 状態を見る（待つ。自分からはキャンセル仕様なし） |
| 競り中 | ⑯へ（入札者の名前が見える） |
| 落札済 | 結果確認。本文閲覧は落札者の⑫ |
| 不落札戻り | 再出品を検討、編集（出品前に戻っている） |

- 新規登録 → ⑦
- 出品確定は **この画面**（⑦ではない）

**出品確定時にユーザーが理解すべきこと**

1. 出品価格と同額がすぐ自分のポイントに入る
2. ディーラーが承認するまで競りは始まらない
3. 売れ残ると、入ったポイントは **全額没収**（目減りとは別）。残高が足りなければ **借金（マイナス）** になる
4. 秘密の次回価格は 20% 下がって返ってくる

#### B. ディーラー担当

自分の出品でなくても、割り当てられた競りが来る。

**置くもの**

- 出品者名
- 秘密の **概要のみ**（本文なし）
- 承認待ち / 進行中の区別
- 辞退する場合の料金（出品価格の 5%）

**操作**

- ⑯へ（詳細・承認・辞退・入札者一覧）
- ここから承認 / 辞退してもよい（⑯と重複してよいが、主操作は⑯の方が情報量に合う）

**状態**

- 担当 0 件（空状態が重要。このタブは出品管理にも使う）
- 承認してくれ、と待たれている
- 進行中（開始後は辞退不可）

**未確定（U3）**: ⑦と⑬のどちらを「新規登録」の主入口にするか。どちらでも登録でき、出品は⑬、でよい

---

### ⑯ 関連秘密詳細（出品者 / ディーラー）

**役割**: ⑬から来る、**自分に関係する 1 件の管理・進行画面。入札しない。**

出品者とディーラーで中身を切り替える（別画面に分けても、1 画面で役割バナーを出してもよい）。

#### 出品者として開いたとき

**置くもの**

- 状態、価格、残り時間（始まっていれば）
- 概要 / カテゴリ / レア度
- **入札者の名前つき履歴**（誰が、いくら、いつ）
- ディーラー名
- 結果（落札額、按分の自分の取り分 70% は終了後）

**操作**

- 見る（入札はできない）
- 競り中にキャンセルする操作は無い

**注意**: 本文を再掲しなくてもよい。主情報は「誰が欲しがっているか」

#### ディーラーとして開いたとき

**置くもの**

- 出品者名
- **概要（進行トークの材料）**
- カテゴリ / レア度 / 現在価格 / 残り時間
- **入札者の名前つき履歴**（盛り上げに使う）
- 承認待ちなら: 承認ボタン、辞退ボタン（料金明示）

**置かない**

- 本文
- 入札 UI

**操作**

- **承認** → その瞬間にオークション開始。開放時間（既定 24 時間）のカウントダウンが始まる。タイムアウトはない。放置すると永遠に始まらない
- **辞退**（開始前のみ）→ 出品価格の 5% 支払い。戻らない。別のメンバーがディーラーになる。何回でも再割当され得る
- 開始後は進行を見るだけ

**状態**

- 承認待ち（主操作ここ）
- 競り中
- 終了
- 辞退直後（別の人が担当になるので、自分の⑯からは消えてよい）

**⑩との違いをレイアウトで示す**

- ⑩: 大きく入札。履歴は匿名
- ⑯: 入札ボタンなし。履歴は顔つき。ディーラーなら承認/辞退

---

### ⑭ マイページ

**役割**: 個人の横断ハブ。ただしポイントの数字はグループ別。

**置くもの**

- グループ別のポイント（一覧。合算して大きく出さない。見せ方としての「全グループ」タブは、**足し算の残高に見えない**こと）
- ポイント履歴（獲得・消費。必ずグループで切る）
- コレクション（落札した秘密。グループタグ付き）→ ⑫
- ⑮への入口
- 称号・所持は後回し（空枠を目立たせない）

**履歴に出る出来事の例**

- チャレンジ報酬
- 出品時の入金
- 不落札による没収
- 落札による支払い
- 出品者としての分配（70%）
- ディーラーとしての分配（30%）
- ディーラー辞退料（5%）

**操作**

- グループで履歴を切り替える
- コレクションを開く
- 設定へ

**注意**

- マイナス残高を履歴と残高の両方で説明できるようにする
- 脱退したグループのポイントは失効。履歴の扱いは「そのグループにいた当時」として残るかは実装依存。無いものとして空でもよい

---

### ⑮ アカウント設定

**役割**: 自分のアカウントと、グループからの抜け方。

**置くもの**

- ニックネーム・アイコンの編集
- ログアウト
- グループ脱退（どのグループかを明示。ポイント失効の警告）
- 通知設定は **MVP では置かない**

**操作**

- プロフィール保存
- ログアウト
- 脱退（最後の幹事は脱退できない、のエラー表示）

**注意**

- 脱退は設定の奥でよい。誤タップでポイントが消えないように確認を厚くする

## 6. 数字・ルール（コピーと確認ダイアログ用）

ユーザー向けに書くときの確定値。調整はあとで行い、今はこれに合わせる。

| こと | 値 |
| --- | --- |
| オークションの長さ | グループ設定。最初は 24 時間。ディーラー承認で開始 |
| 開始価格 | 出品者が付けた価格と同じ |
| 出品した瞬間 | その価格と同額が自分に入る |
| 落札時の分け方 | 落札額の 出品者 70% / ディーラー 30%。追加ボーナスなし |
| 売れ残ったとき | 入っていた前払いを全額没収。秘密の次回価格は 20% ダウン |
| 借金 | 上限なし。入札では借金を増やせない（残高不足は入札不可） |
| ディーラー辞退 | 開始前のみ。料金は出品価格の 5%。戻ってこない |
| レア度 | 1〜5 の自己申告 |

8. ⑧ チャレンジ枠（中身は仮）
