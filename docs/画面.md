### 画面一覧（全体まとめ）

#### 認証・グループ管理系

| 画面 | 主な機能 |
| --- | --- |
| **① オンボーディング・ログイン** | 初回起動時のアカウント作成、ニックネーム・アイコン設定 |
| **② グループ切り替え画面** | 所属グループを一覧表示（アイコン・未読数・保有ポイント）、タップで切り替え |
| **③ グループ参加画面** | 招待コード入力 / QRコード読み取りで新規グループに参加 |
| **④ グループ作成画面** | グループ名・アイコン設定、招待コード/招待リンク発行 |
| **⑤ グループ管理画面（幹事用）** | メンバー管理、オークション開催スケジュール設定（管理者になっているグループを選んでから操作）。~~ショップ価格設定~~（廃止） |

#### メイン機能系（すべて「選択中のグループ」に紐づく）

| 画面 | 主な機能 |
| --- | --- |
| **⑥ ホーム（ダッシュボード）** | 現在のグループ名表示＋切り替え導線、保有ポイント、開催中オークションのハイライト、お知らせ |
| **⑦ 秘密登録画面** | カテゴリ・レア度・本文入力、**公開先グループの複数選択**、公開タイミング設定 |
| **⑧ ミニゲーム/チャレンジ一覧** | ゲーム一覧、現実チャレンジの写真提出＆承認フロー、挑戦履歴・クールダウン表示 |
| **⑨ オークション一覧** | 出品中の秘密をカード表示（カテゴリ・レア度・現在価格・残り時間）、ソート/フィルター |
| **⑩ オークション詳細・入札画面** | 現在価格・入札履歴、入札ボタン、カウントダウン、ウォッチリスト |
| **⑪ ショップ画面** | ~~カテゴリタブ、固定価格商品の購入、購入確認モーダル~~ **廃止（実装しない）**。秘密獲得はオークションのみ（`オークションルール.md`） |
| **⑫ 秘密ビューワー（落札後）** | 落札した秘密の本文表示、リアクション/コメント |
